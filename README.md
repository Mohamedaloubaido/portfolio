# Mohammed Al-Obaido — Portfolio

Personal portfolio built with Next.js and TypeScript.

## Purpose

A focused professional portfolio for opportunities in:

- Data Entry
- CRM Operations
- Administration
- Operations
- Data Quality & Reporting
- Selected Digital / Product roles

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production

Designed for direct deployment to Vercel from GitHub.
